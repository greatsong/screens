# 학교 행사 자동 연동

## 운영 흐름

1. 배움이음 v3에서 새 프로그램을 만들면 `screenEnabled=true`가 기본값입니다. 설계 초안은 게시하지 않습니다. 기존 시드·복사한 프로그램은 스크린 안내를 선택해야 합니다.
2. 담당교사가 개설하면 학생용 안내·대상 학년·회차 일정만 공개 행사로 내보냅니다.
3. Google 연동 작업이 신청 Forms를 생성·게시하고 응답 주소를 확인한 뒤 `bind_recruitment_form(user, program_id, form_response)`를 호출합니다. `form_response`는 Forms API의 `formId`, `responderUri`를 포함합니다. HTTP 진입점은 `POST /api/programs/:id/integrations/google/recruitment-form`이며 현재 로그인한 담당교사에게만 허용합니다. 실제 Google 자원 생성·OAuth는 배움이음의 Google 통합 작업 범위이며 이 브리지가 수행하지 않습니다.
4. 이 맥의 LaunchAgent가 60초마다 변경을 확인합니다. 바뀐 공개 피드만 GitHub `projects/integrations/<source>.json`에 올립니다. GitHub Pages 편성·배포 뒤 A에는 행사 소개, B에는 신청 안내와 QR이 표시됩니다. A에서도 신청 QR을 제공합니다. 배포·캐시 시간과 화면 확인 간격(30초)이 더해지므로 60초 내 표시를 보장하지 않습니다.
5. 신청 주소가 아직 없으면 행사 안내만 표시합니다. Forms 응답 주소가 저장되면 자동으로 QR을 추가합니다. Classroom 교실 주소·가입 코드는 모집 전 신청 QR에 사용하지 않습니다.
6. 수정·스크린 안내 해제·모집 마감도 다음 동기화에서 반영합니다. 게시 종료일(한국 시간)이 지나면 인터넷이 끊겨도 화면 자체에서 내립니다. 종료일이 없으면 마지막 회차 날짜, 회차 날짜도 없으면 개설 후 30일을 사용합니다.

## 공개 범위와 장애 처리

공개 필드는 행사 ID·제목·학생 안내·대상 학년·일정·신청 응답 주소·게시 종료 시각뿐입니다. 학생 이름·이메일·신청자·상담·관찰·학생부·교사용 메모·Forms 편집 링크·응답은 보내지 않습니다. 실제 교실의 가입 코드도 보내지 않습니다.

기존 시연 데이터는 `screenEnabled`가 없어 내보내지 않습니다. 테스트 이벤트는 임시 DB와 로컬 미리보기에서만 사용합니다.

소스 DB를 읽지 못하거나 네트워크가 끊기면 마지막 성공 상태를 유지하고 다음 60초 주기에 재시도합니다. 소스 오류를 빈 목록으로 덮어쓰지 않습니다. 마지막 공개 피드에는 24시간 유효기간을 부여하고 6시간마다 갱신합니다. 맥이 오래 꺼지면 행사 카드는 최대 24시간 뒤 자동으로 내려갑니다. GitHub Actions는 이 맥의 비공개 DB에 접근하지 않습니다. 이 맥이 켜져 있고 로그인되어 있어야 변경을 전달할 수 있습니다.

## 다른 프로젝트 연결

`integrations/sources.json`에 소스를 등록합니다. 프로젝트 위치는 `GREATSONG_ROOT` 또는 상위 폴더의 `paths.json`에서 가져옵니다. 소스 예:

```json
{"id":"another-project","project":"another-project","adapter":"json-file","file":"exports/screens-events.json","enabled":true}
```

해당 파일은 아래 형식의 공개용 사본이어야 합니다. 피드 ID는 소스 ID와 같아야 하며 행사 ID는 한 소스 안에서 유일해야 합니다. 미리보기·검사를 거친 학생용 안내만 작성합니다.

```json
{"schemaVersion":1,"source":"another-project","events":[{"id":"event-1","title":"행사명","summary":"학생 안내","grades":"2학년","start":"2027-05-01","end":"2027-05-03","until":"2027-05-04T00:00:00+09:00","signupUrl":""}]}
```

`signupUrl`은 생성한 공개 HTTPS 신청 주소이며 준비 전에는 빈 문자열입니다. 로컬 주소나 Google Forms 편집 주소를 사용하지 않습니다. 가입 후 확정자만 볼 수 있는 Classroom 링크를 공개 신청 주소로 대체하지 않습니다.

## 점검과 재설치

- 읽기 전용 확인: `python3 scripts/sync_integrations.py --output .local/preview`
- 수동 동기화: `python3 scripts/sync_integrations.py --publish`
- 자동 실행 설치: `python3 scripts/install_integration_agent.py --install`
- 로그: `.local/integrations.log`, `.local/integrations-error.log`
- launchd 라벨: `kr.greatsong.screens-integrations`
- 중지: `launchctl bootout gui/$(id -u)/kr.greatsong.screens-integrations`

다른 맥으로 옮기거나 경로를 다시 바꾸면 자동 실행 설치 명령을 다시 실행합니다. 자격 증명은 gh CLI의 기존 로그인을 사용하며 코드나 plist에 토큰을 넣지 않습니다. `.local/`은 Git에서 제외합니다.
