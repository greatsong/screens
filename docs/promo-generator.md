# 홍보 영상 자동 제작 기능 설계

교사(또는 승인받은 학생회·동아리)가 콘셉트 문장과 참고 이미지를 넣으면, 15초 안팎의 홍보 영상을 만들어 검토를 거친 뒤 스탠바이미 A 화면에 편성하는 기능이다. 「2027 두근두근 당곡」을 만든 과정(장면 설계 → 음악·효과음 → 렌더 → 배포)을 그대로 자동화한다.

## 1. 전체 흐름

| 단계 | 하는 곳 | 내용 | 걸리는 시간 |
|---|---|---|---|
| 1 요청 | 관리 화면(Apps Script) | 제목, 콘셉트, 꼭 넣을 문구, 길이, 분위기, 참고 이미지 | 교사 1분 |
| 2 접수 | 관리 시트 '홍보' 탭 + 드라이브 폴더 | 요청 저장, 이미지 보관, 상태 '접수' | 즉시 |
| 3 제작 | 맥미니(작업 실행 컴퓨터) | 대본·장면 설계 → 음악·효과음 → 렌더 → 자동 검수 | 5~10분 |
| 4 미리보기 | 관리 화면 | 영상, 장면 시트, 검수 결과를 보고 승인·수정 요청·버림 | 교사 1분 |
| 5 편성 | GitHub Pages | `site/promo/<id>.mp4` 배포, A 화면 순환에 영상 카드로 들어감 | 1~2분 |

상태: 접수 → 제작 중 → 검토 대기 → (수정 요청 → 제작 중) → 게시 중 → 기간 종료·숨김. 수정 요청은 같은 요청에 한 줄 의견을 붙여 다시 만든다.

## 2. 요청 양식 (관리 화면)

| 항목 | 필수 | 예 |
|---|---|---|
| 제목 | 필수 | 2027 두근두근 당곡 |
| 콘셉트 | 필수 | 2026년은 지나갔지만 2027년엔 두근두근한 일이 많다. 밝고 경쾌하게 |
| 꼭 넣을 문구 | 필수 | 다섯 분야 프로그램 안내, COMING SOON, 당곡고등학교 |
| 도입·흐름 메모 | 선택 | 처음엔 하트비트와 ㄷㄱ, 두근두근 당곡!!부터 신나게 |
| 참고 이미지 | 선택 | 포스터, 행사 사진, 로고 (최대 5장) |
| 길이 | 선택 | 10초 / 15초(기본) / 30초 |
| 분위기 | 선택 | 경쾌 / 감성 / 웅장 / 귀여움 |
| 게시 기간 | 선택 | 시작일·종료일. 종료일이 지나면 자동으로 내림 |

## 3. 제작 (맥미니)

맥미니를 GitHub Actions 작업 실행 컴퓨터(self-hosted runner)로 등록하고, 홍보 요청이 들어오면 「홍보 영상 제작」 워크플로가 맥미니에서 돈다. 렌더에 Chrome과 ffmpeg가 필요하고 한 편에 수 분이 걸려서, 무료 클라우드보다 맥미니가 알맞다.

1. **대본·장면 설계 (Claude API)**: 콘셉트·문구·이미지를 받아 장면 표(시간, 화면 문구, 움직임, 전환, 효과음)를 만든다. 박자(예: 128BPM) 위에 장면 경계를 놓는다. 학생이 읽는 문구는 솔라 프로4가 다듬는다.
2. **장면 코드**: 검증된 장면 틀(하트비트 도입, 단어 착지, 숫자 굴림, 분야 나열, 원 와이프 전환, 폭죽 피날레 등)을 조합하고 색·문구·이미지를 채운다. 매번 백지에서 코드를 쓰지 않아 실패가 적고 품질이 고르다.
3. **음악·효과음**: 음악은 합성(synth_music) 또는 ElevenLabs Music, 효과음(함성, 폭죽, 휙)은 미리 만든 소리 모음에서 고른다. 크레딧을 아끼고 같은 소리를 학교 영상의 '시그니처'처럼 쓴다.
4. **렌더**: 1920×1080 30fps mp4, -14 LUFS.
5. **자동 검수**: 깜빡임(1초 3회 초과 금지), 멈춘 화면, 글자가 화면 밖으로 나가는지, 길이·음량. 실패하면 한 번 자동으로 고쳐 다시 렌더하고, 그래도 실패하면 '검토 대기'에 실패 사유를 붙인다.
6. **결과 업로드**: 영상과 장면 시트(1초 간격 정지 화면)를 드라이브에 올리고 관리 시트 상태를 바꾼다. 교사에게 "검토할 홍보 영상" 메일.

## 4. 스탠바이미 편성

- `content.json`에 `promos: [{id, title, src, until, every}]`을 더한다. `every`는 소식 카드 몇 장마다 한 번 나올지(기본 4).
- A 화면은 영상 카드 차례가 오면 소리 없이 재생하고 영상 길이만큼 머문다. 두 화면의 시계 동기는 영상 길이를 포함해 그대로 유지된다.
- B 화면에서는 같은 시각에 영상의 핵심 문구와 QR(관련 안내 페이지가 있으면)을 보여 준다.
- 소리: 공용 공간 기본은 무음. 관리 화면에서 '소리 켜기'를 고르면 영상 카드에서만 소리를 낸다(스탠바이미에서 한 번 터치해 소리를 허용해 두어야 함).

## 5. 권한과 안전

- 요청은 교사 계정(ADMIN_EMAILS)만. 학생회·동아리 요청은 교사가 대신 넣거나, 별도 '홍보 요청 설문'으로 받아 교사가 승인한다.
- 실존 인물 얼굴은 생성하지 않는다. 사진은 업로드된 것만 쓰고, 학생 얼굴이 나오면 게시 동의를 확인한다.
- 다른 기관 로고·캐릭터를 흉내 내지 않는다.
- 긴급 정지·숨김은 홍보 영상에도 똑같이 적용된다.

## 6. 만드는 순서

| 단계 | 내용 | 맥미니 필요 |
|---|---|---|
| 1 | 영상 카드: 이미 만든 mp4를 관리 화면에서 올리면 A 화면에 편성 (지금 「2027 두근두근 당곡」을 바로 넣을 수 있음) | 아니요 |
| 2 | 장면 틀 라이브러리: 이번 영상의 장면들을 문구·색만 바꿔 쓰는 틀로 정리 | 아니요 |
| 3 | 요청 양식과 '홍보' 탭, 상태 추적, 검토 화면 | 아니요 |
| 4 | 맥미니 작업 실행 컴퓨터 등록, 「홍보 영상 제작」 워크플로 | 예 |
| 5 | 대본·장면 설계 자동화(Claude API)와 자동 검수·재시도 | 예 |

1~3단계는 맥미니 없이 바로 만들 수 있고, 그 사이에는 요청을 받아 제가 이 대화처럼 영상을 만들어 올리는 반자동으로 운영할 수 있다.

## 7. 정해야 할 것

- 요청할 수 있는 사람: 교사만 / 학생회·동아리까지
- 공용 공간에서 소리를 낼지
- Claude API 키를 맥미니에 둘지(사용량 한도 설정 포함)
