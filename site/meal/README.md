# 급식 아이콘

급식 카드에 쓰는 음식 그림이다. Codex CLI의 이미지 생성으로 만든 애니메이션풍 그림(2026-10-30)을
투명 여백을 잘라 192px WebP로 줄였다. 파일 이름은 `site/app.js`의 `MEAL_ICON`에서 메뉴 이름으로 고르는 열쇠다.
맞는 열쇠가 없으면 `dish`(급식 식판)를 쓰고, 파일이 없으면 그림만 숨긴다.

새 아이콘이 필요하면 같은 그림체 문구로 Codex에 만들게 하고, `MEAL_ICON`에 메뉴 이름 규칙을 더한다.

## 요리별 그림(d/)

`d/<번호>.webp`는 나이스 식단표에 실제로 나온 메뉴마다 따로 그린 그림입니다(Codex 이미지 생성, 256px).
번호는 메뉴 열쇠(앞말·괄호·곁들임 소스·띄어쓰기를 뺀 이름)의 SHA-1 앞 10자리이고, 열쇠 → 번호 목록은 `site/meal-dishes.js`에 있습니다.
화면은 요리별 그림을 먼저 찾고, 없으면 이 폴더의 분류 그림을 씁니다. 앞으로 나올 메뉴와 2026년에 나온 메뉴를 그렸습니다(2026년 10월 31일 기준 439종).
